# Fonologia: la pipeline italiano → romanesco

Regole ordinate. Applicale in sequenza: alcune si innescano a vicenda
(*il caldo* → rotacismo → *er caldo* → assimilazione LD → **er callo**).

Ogni regola ha un peso: **[base]** = sempre, anche in R1. **[piena]** = solo R2.
**[lex]** = solo nelle parole elencate, non è produttiva — non applicarla per analogia.

---

## 1. Articoli e preposizioni articolate [base]

| Italiano | Romanesco | Nota |
|---|---|---|
| il, lo | **er** | *er sole, er core, er zucchero* |
| i, gli | **li** | *li amici, li sordi* |
| la, le | la, le | restano; nel parlato veloce *'a, 'e* |
| un, uno | **'n, 'no** | *'n attimo* |
| una | **'na** | *'na cosa* |
| del, dello | **der** | *der pane* |
| nel, nello | **ner** | *ner sacco* |
| al, allo | **ar** | *ar bar, ar volo* |
| dal | **dar** | *dar macellaro* |
| sul | **sur** | *sur serio* |
| con il, col | **cor** | *cor cavolo* |
| dei, degli | **de li** | *de li mortacci* (attenzione: imprecazione) |

Gli articoli che cominciano per *l* tendono a perdere la consonante in aferesi:
è tratto parlato, in scrittura usalo con misura o la pagina diventa illeggibile.

## 2. Rotacismo: L → R davanti a consonante [base]

Il tratto più riconoscibile. *l* seguita da consonante diventa *r*.

alto → **arto** · caldo → **callo** (vedi §4) · colpa → **corpa** · soldi → **sordi** ·
calcio → **carcio** · volta → **vorta** · molto → **morto** · falso → **farso** ·
alcuni → **arcuni** · il tuo → **er tuo** · palco → **parco**

**Non si applica** a *l* intervocalica (*pelle* resta *pelle*) né a inizio parola (*luna*).
Caso a parte: *altro* → **antro** (forma corrente) o *artro*. Usa **antro**.

## 3. Assimilazione ND → NN [base]

Vivissima, produttiva: applicala sempre.

quando → **quanno** · mondo → **monno** · grande → **granne** · andare → **annà** ·
secondo → **seconno** · prendere → **prenne** · scendere → **scenne** · quando mai → **quanno mai** ·
rispondere → **risponne** · tondo → **tonno** · vendere → **venne**

## 4. Assimilazioni lessicalizzate [lex]

- **LD → ll**: sopravvive solo in *caldo* → **callo**, *caldaia* → **callara**, e derivati.
- **MB → mm**: oggi rarissima. Solo in forme fossili tipo *piombo* → *piommo*. Non estenderla.

Se non è in questa lista, non applicarla: *bambino* resta *bambino*, non *bammino*.

## 5. GL → J [base]

figlio → **fijo** · famiglia → **famija** · moglie → **moje** · meglio → **mejo** ·
aglio → **ajo** · voglio → **vojo** · sbagliato → **sbajato** · tagliare → **tajà** ·
foglio → **fojo** · togliere → **tojje**

## 6. Infiniti tronchi (apocope) [base]

Le tre coniugazioni perdono il *-re* e prendono l'accento sull'ultima:

| Italiano | Romanesco |
|---|---|
| -are | **-à**: parlare → *parlà*, mangiare → *magnà*, andare → *annà* |
| -ere (tronchi) | **-é**: avere → *avé*, vedere → *vedé*, sapere → *sapè*, potere → *potè* |
| -ire | **-ì**: dormire → *dormì*, venire → *venì*, finì |
| monosillabi | fare → **fà**, dire → **dì**, stare → **stà**, dare → **dà** |

I verbi **piani** (accento sulla penultima) non si troncano, si assimilano:
*prendere* → **prenne**, *mettere* → **mette**, *scrivere* → **scrive**, *leggere* → **legge**.

## 7. Aferesi e troncamenti [base]

questo/a → **'sto / 'sta** · questi/e → **'sti / 'ste** · adesso → **mo'** ·
non → **nun** · niente → **gnente** · nemmeno/neanche → **manco** · una → **'na** ·
insomma → **'nsomma** · ancora → **'ncora** · bene → **be'** · sono → **so'** ·
quello → **quer** (davanti a consonante: *quer tipo*) · guarda → **uarda**

## 8. Perifrasi progressiva con "a" [base]

Il gerundio va sostituito: **stare a + infinito**.

sto facendo → **sto a fà** · stavo dicendo → **stavo a dì** · che stai facendo? → **che stai a fà?** ·
stanno mangiando → **stanno a magnà**

È uno dei marcatori più forti: se manca, la resa sembra italiano con qualche apostrofo.

## 9. Il "ce" attualizzante [base]

Il romanesco appiccica un *ce/ci* atono ai verbi di possesso, percezione e stato.

ho una macchina → **c'ho 'na macchina** · non capisco → **nun ce capisco** ·
non vedo → **nun ce vedo** · hai fame? → **c'hai fame?** · non ho tempo → **nun c'ho tempo** ·
ci penso io → **ce penso io** · non ci credo → **nun ce credo**

Vedi *avecce* in `morfologia.md`.

## 10. Consonanti e altri tratti [piena]

- **b, g intervocaliche rafforzate**: *roba* → **robba**, *sabato* → **sabbato**, *regina* → **reggina**.
  In scrittura usane poche: rendono il testo faticoso.
- **-gn-**: *niente* → **gnente**, *mangiare* → **magnà**, *bagno* resta *bagno*.
- **s + consonante iniziale** con vocale d'appoggio: *sto* → *'sto*, già coperto.
- **Raddoppiamento fonosintattico** (*a ccasa*, *è ppieno*): esiste nel parlato, **non scriverlo**.
  È rumore visivo, non aggiunge romanità alla pagina.
- **-eno in 3ª plurale**: *dicono* → **diceno**, *vengono* → **vengheno**, *erano* → **ereno**.

## 11. Prosodia (per chi legge ad alta voce) [nota]

Cadenza discendente a fine frase, vocali toniche lunghe, ritmo strascicato sulle sillabe
accentate: *"aòoh, ma che ffai?"*. In scrittura si rende con la punteggiatura corta e
qualche vocale doppia in interiezione (*aòh*, *daje*), **non** con l'accumulo di apostrofi.

## Errori tipici da evitare

| Sbagliato | Giusto | Perché |
|---|---|---|
| *bammino, tammuro* | bambino, tamburo | MB→mm non è più produttiva |
| *pelle → perre* | pelle | il rotacismo vuole *l* + consonante |
| *sto mangiando* | sto a magnà | senza la perifrasi non è romanesco |
| *ho fame* (in R2) | c'ho fame | manca il *ce* attualizzante |
| *nun so'ann'ato* | nun so' annato | apostrofi a caso: leggi ad alta voce prima |
| tre interiezioni in due righe | una ogni due frasi | è il confine tra romano e macchietta |
| *si sai, si nun hai* | *se sai, se nun hai* | il condizionale resta *se*: *si* è solo l'affermazione o il riflessivo |
